## Aperçu

Un site web moderne et responsive développé avec React et Vite, offrant une interface utilisateur claire et intuitive. Ce projet utilise les technologies web modernes afin d'offrir une expérience utilisateur fluide.

## Fonctionnalités principales

- **Développement rapide avec Vite**
- **React pour une architecture basée sur les composants**
- **Tailwind CSS pour un style moderne**
- **Hot Module Replacement (HMR)**
- **Design responsive**
- **ESLint pour la qualité du code**

## Technologies utilisées

- **React** : bibliothèque d'interface utilisateur
- **Vite** : outil de build et serveur de développement
- **Tailwind CSS** : framework CSS utilitaire
- **React Icons** : bibliothèque d'icônes
- **ESLint** : outil d'analyse et de qualité du code
- **Node.js**
- **npm**
- **VS Code**
- **Chrome DevTools**

## Défis et apprentissages

L'un des principaux défis consistait à créer un site web responsive et convivial tout en maintenant un code React organisé et facilement maintenable. Grâce à ce projet, j'ai renforcé mes compétences en React, Tailwind CSS, design responsive et développement basé sur les composants. J'ai également appris à utiliser Vite, ESLint et Chrome DevTools afin d'améliorer mon flux de développement, de déboguer les problèmes et de maintenir la qualité du code.

# Résultat

J'ai développé un site web moderne et responsive pour l'association MALOU de l'Université d'Ottawa, permettant de rendre les informations et les ressources de l'association plus faciles à consulter et à naviguer. Le projet a fourni une base React évolutive pour de futures fonctionnalités tout en renforçant mon expérience pratique en développement frontend, UI/UX et développement web dans un contexte réel.
