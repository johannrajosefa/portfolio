## Overview

A modern, responsive website built with React and Vite, featuring a clean and intuitive user interface. This project leverages the latest web technologies to deliver a seamless user experience.

## Key Features

- **Fast development with Vite**
- **React for component-based architecture**
- **Tailwind CSS for modern styling**
- **Hot Module Replacement (HMR)**
- **Responsive design**
- **ESLint for code quality**

## Technologies Used

- **React**: UI library
- **Vite**: Build tool and development server
- **Tailwind CSS**: Utility-first CSS framework
- **React Icons**: Icon library
- **ESLint**: Code linting
- **Node.js**
- **npm**
- **VS Code**
- **Chrome DevTools**

## Challenges and Learnings

One of the main challenges was creating a responsive and user-friendly website while keeping the React code organized and maintainable. Through the project, I strengthened my skills in React, Tailwind CSS, responsive design, and component-based development. I also learned how to use Vite, ESLint, and Chrome DevTools to improve my development workflow, debug issues, and maintain code quality.

# Outcome

I developed a modern and responsive website for the MALOU Association at the University of Ottawa, making association information and resources easier to navigate and access. The project provided a scalable React foundation for future features while strengthening my practical experience in frontend development, UI/UX, and real-world web development.
