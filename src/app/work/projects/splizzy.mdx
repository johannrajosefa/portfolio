## Overview

Splizzy is a user-friendly mobile application designed to simplify the process of splitting expenses among groups. Whether you're dining out with friends, managing shared household costs, or planning a trip, Splizzy helps you track expenses, assign them to individuals, and calculate what each person owes, all in real-time.

## Key Features

- **Group expense management**
- **Automatic expense splitting calculations**
- **Secure user authentication**
- **Cross-platform support (iOS and Android)**
- **Real-time data synchronization**
- **Modern and intuitive user interface**

## Technologies Used

- **Flutter**: Cross-platform mobile development framework
- **Provider**: State management solution
- **Google Fonts**: Typography
- **Flutter Launcher Icons**: App icon management
- **Firestore**: Real-time database
- **Firebase Authentication**: User authentication
- **Google Sign-In**: Social authentication
- **Flutter SDK (^3.7.0)**
- **Dart SDK**
- **Android Studio / Xcode**
- **VS Code**

## Challenges and Learnings

One of the main challenges was developing a real-time expense-splitting system that could accurately calculate each user's share while keeping data synchronized across multiple users. Working as a team also required coordinating development and maintaining a consistent code structure. Through the project, I strengthened my skills in Flutter, Firebase, Provider state management, and collaborative development while learning how to design reusable components and manage real-time application data.

# Outcome

We developed a cross-platform mobile application that allows users to create groups, manage shared expenses, and automatically calculate what each person owes. The project provided hands-on experience building a real-world application with authentication, real-time database synchronization, state management, and a collaborative software development workflow.
